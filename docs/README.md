# Общее описание проекта
В этом проекте содержатся функции для подсчёта площадей и периметров геометрических фигур.
В проекте содержатся
1. `circle.py` - программа с функциями для круга
2. `rectangle.py` - программа с функциями для прямоугольника
3. `square.py` - программа с функциями для квадрата
4. `triangle.py` - программа с функциями для треугольника 

## Описание функций с примерами вызова

### 1. Круг (circle.py)
* __`area(r)`__
    * **Описание** 
        * Принимает радиус круга и возвращает его площадь
    * **Пример вызова** 
        ```py
        print(area(10))
        output: 314.1592653589793
        ```
* __`perimeter(r)`__
    * **Описание** 
        * Принимает радиус круга и возвращает его периметр
    * **Пример вызова** 
        ```py
        print(perimeter(10))
        output: 62.83185307179586
        ```

### 2. Прямоугольник (rectangle.py)
* __`area(a, b)`__
    * **Описание** 
        * Принимает стороны прямоугольника и возвращает его площадь
    * **Пример вызова** 
        ```py
        print(area(5,10))
        output: 50
        ```
* __`perimeter(a, b)`__
    * **Описание** 
        * Принимает стороны прямоугольника и возвращает его периметр
    * **Пример вызова** 
        ```py
        print(perimeter(5,10))
        output: 30
        ```
        
### 3. Квадрат (square.py)
* __`area(a)`__
    * **Описание** 
        * Принимает сторону квадрата и возвращает его площадь
    * **Пример вызова** 
        ```py
        print(area(7))
        output: 49
        ```
* __`perimeter(a)`__
    * **Описание** 
        * Принимает сторону квадрата и возвращает его периметр
    * **Пример вызова** 
        ```py
        print(perimeter(7))
        output: 28
        ```
        
### 4. Треугольник (triangle.py)
* __`area(a, h)`__
    * **Описание** 
        * Принимает сторону треугольника и высоту,проведенную к этой стороне, и возвращает его площадь
    * **Пример вызова** 
        ```py
        print(area(7, 6))
        output: 21
        ```
* __`perimeter(a, b, c)`__
    * **Описание** 
        * Принимает стороны треугольника и возврщает его периметр
    * **Пример вызова** 
        ```py
        print(perimeter(7, 10, 11))
        output: 28
        ```
